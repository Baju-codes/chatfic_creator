Let's say we keep search engine at default. In the search box, we want to have the query "Who" and we want the search's autocomplete sugestions to give the following two options: "Who is the Doctor?" and "Who is the man in the blue police box?"

So we will write "Who" into the text field labled 'search box'. We will keep the 'did you mean' text field empty, and into the 'Autocomplete answers' text box, we will write just the text we want to go after the search query. We will also separate each autocomplete sugestion with an enter. (ie: we will type "is the Doctor?", we will hit enter and then type "is the man in the blue police box?")

The generator supports three preset search engines and a custom one. The presets have their look already defined. For the custom search, you can specify the name (what text will apear on top of the search bar) using the "Custom Search Engine name" textbox and the color with the color picker. (These two inputs apear only when you select a custom search engine)
Please note that the color of the custom search engine is coded into the workskin. This means two things: 1) You can't have multiple custom search engines within one work unless they all have the same color (or unless you change the workskin and the html a bit). 2) Any time you change the color of the custom search engine, you will have to update the workskin on AO3.
This also means that if you keep the same color, or you are not using the custom search engine, you do not need to update your workskin on AO3 and can use it for multiple works. (ie: the workskin provided when you submit the form already has the code for the three default search engines).
A workskin is AO3's way of implementing styles. It can be used to show text in different fonts, to change how your fic looks, and, in our case, it is used to make the search engine look like the preview instead of raw code.
Wen you submit the form, you will see the code you have to paste into your AO3 workskin. To create a skin, you will go to your AO3 dashboard, click on the button "skins", then "my work skins" and "create work skin". There, you will copy all the code below. You can also add this code to an existing workskin by editing it!
When you want to apply the workskin to a particular work, you will select the workskin (the last field in the "Associations" part of the work creation) and then copy the HTML text from above into the "HTML" text editor.
