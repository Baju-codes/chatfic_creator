A name of "Tony" and username of "TheRealTonyStark" will let you write Tony's messages as "Tony: message" instead of having to type "TheRealTonyStark: message" over and over and over again. The final text will still display all messages by Tony as being written by "TheRealTonyStark".

How to format messages

A single message is written in the format "name: message".
A reply is written in the format "sender,receiver: message".
Please separate individual messages by pressing enter (ie: one message on each line). If you don't do this, the output will be wrong.

Example:

Let's say we have the name "Steve" with the username "CaptainAmerica" and the name "Tony" with the username "TheRealTonyStark".
The following text:
Steve: hey there, I'm captain america
Tony: Yeah, we know Steve, you set it as your username.
Steve,Tony: Oh I see!

will result in a preview:

CaptainAmerica: hey there, I'm captain america
TheRealTonyStark: Yeah, we know Steve, you set it as your username.
CaptainAmerica replied to TheRealTonyStark: Oh I see!
And a raw HTML:

<p><b>CaptainAmerica</b>: hey there, I'm captain america</p>
<p><b>TheRealTonyStark</b>: Yeah, we know Steve, you set it as your username.</p>
<p><b>CaptainAmerica</b> replied to <b>TheRealTonyStark</b>: Oh I see!</p>
You can then copy the HTML and paste it directly into your AO3 story (into the raw HTML tab)

Example:

There are two special message types. Messages in the form "time:message" will show up without a name and can be used to show time passing.
Messages in the form "name:typing" will show that character typing.
The following text:
time: Today 2PM
Tony:typing

will result in a preview:

Today 2PM
TheRealTonyStark is typing...

And a raw HTML:

<p>Today 2PM </p>
<p><b>TheRealTonyStark</b> is typing... </p>
You can then copy the HTML and paste it directly into your AO3 story (into the raw HTML tab)
