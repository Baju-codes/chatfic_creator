# chatfic_creator
A website that lets you write fake chat conversations. It formats your text and provides a raw HTML text to be pasted elsewhere for all your AO3 needs!

How to use:
Step 1: Add the names and usernames of the people involved in the conversation.
Step 2: Write messages in the format "name: message".
Step 3: Write replies in the format "sender, reciever: message".
Step 4: Copy the HTML formating of your final chat
Step 5: Profit!
