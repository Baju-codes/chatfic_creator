Welcome to the Chat Message Creator

This website allows you to create chat-like conversations from plain text. This way you can focus on getting to the heart of your story and letting the website worry about formatting! The website will also create a ready-to-use text with HTML tags so the formatting shows up on websites or on AO3!

We offer two different styles for formats:

User1: Hi!

User2: Hey there!

User1 replied to User2: What a wonderful day we have today

User2 replied to User1: This is an example conversation

Hi!
