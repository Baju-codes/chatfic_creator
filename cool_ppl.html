Opacity:
you can change the opacity of text by adding this line to any workskin:
#workskin.opacity{
opacity: [number]%;
}

If in your work, you then write text in the form "<p class="opacity">TEXT HERE<p>" it will lower the opacity of the text to the percentage set in the workskin.

Like this:
#workskin.opacity{
opacity: 40%;
}

Rotation:
Text can be rotated by adding this line to any workskin:
#workskin .tilt {
transform: rotate([degrees]);
position: absolute;
}

If in your work, you then write text in the form "<p class="tilt">TEXT HERE<p>" it will lower the opacity of the text to the percentage set in the workskin.

Like this:
#workskin .tilt {
transform: rotate(-30deg);
position: absolute;
}
